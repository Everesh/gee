# gee

... I wonder where my disk space went

Visualize the mess you, ___yes, you in particular___, made out of your fs

![preview gif](https://github.com/user-attachments/assets/b5171b3f-f4ea-4681-8610-5d6d49e457a1)

### Install
```sh
go install github.com/Everesh/gee@latest
```

### Usage
```sh
gee <?path>
```

> [!TIP]
> If you leave path blank, current working directory will be used
